# Vinyl Language Support

Language support and LSP integration for the **Vinyl** programming language in Visual Studio Code.

## Features

- **Syntax Highlighting**: Full syntax support for `.vinyl` files.
- **Language Server Protocol (LSP)**: Autocompletion, diagnostics, go-to-definition, and hover info via `vinyl-lsp`.

## Requirements

Ensure `vinyl-lsp` is built and available on your system path.
